VisionNav Guía de instalación

Instale VisionNav en su computador

Cinco pasos, la mayoría con doble clic. No necesita saber programar.

  • Windows 10 u 11
  • Unos 15 minutos
  • Unos 2 GB libres
  • Conexión a internet

1

Instalar Python

Python es un programa gratuito que VisionNav necesita para funcionar. Si ya lo tiene instalado, marque este paso como hecho y siga.

  1. Descargue Python desde su página oficial.
  2. Abra el archivo descargado.
  3. Marque la casilla «Add python.exe to PATH», que está abajo en la primera ventana.
  4. Haga clic en «Install Now» y espere a que termine.
Descargar Python

Si olvida marcar la casilla del punto 3, el instalador de VisionNav no encontrará Python.

2

Descargar VisionNav

Descargue el proyecto en un archivo comprimido (ZIP) y descomprímalo en una carpeta fácil de encontrar, como Documentos.

Descargar VisionNav (ZIP)

Para descomprimir: clic derecho sobre el archivo, luego «Extraer todo» y «Extraer».

3

Conseguir las claves

VisionNav usa dos servicios gratuitos: uno escribe la descripción de la escena y el otro la lee en voz alta. Cada uno le da una clave, que funciona como una contraseña. Guárdelas en un bloc de notas; las necesitará en el paso 4.

  • Groq, para la descripción: inicie sesión y haga clic en «Create API Key».
  • Azure AI Speech, para la voz: en el portal de Azure cree un recurso «Speech» con el plan gratuito (F0). En «Claves y punto de conexión» copie la Clave 1 y anote la Región (por ejemplo, canadacentral).
Abrir Groq Abrir Azure AI Speech

No comparta sus claves con nadie. Solo se guardan en su computador.

4

Instalar

Abra la carpeta de VisionNav y haga doble clic en instalar.bat. Se abrirá una ventana negra que hace todo por usted:

  1. revisa que Python esté instalado;
  2. descarga lo que VisionNav necesita (es la parte más demorada);
  3. descarga el modelo que reconoce los objetos y comprueba que esté completo;
  4. le pide las dos claves del paso 3. Péguelas con clic derecho y presione Enter.

Cuando lea «Instalación terminada», puede cerrar la ventana.

Si Windows muestra «Windows protegió su PC», haga clic en «Más información» y luego en «Ejecutar de todas formas». Es un aviso normal con archivos descargados de internet.

5

Iniciar

Haga doble clic en iniciar.bat. Unos segundos después se abrirá en su navegador la página para probar VisionNav.

La ventana negra debe quedar abierta mientras use VisionNav. Para apagarlo, ciérrela. La próxima vez solo tiene que abrir iniciar.bat; no hace falta instalar de nuevo.

VisionNav está instalado

Ahora puede probarlo con una imagen.

Ver cómo usarlo

Usar VisionNav

VisionNav recibe una foto de una escena y le devuelve una descripción de lo que hay a su alrededor, en texto y en audio.

En esta sección

  1. 1Probar con una imagen
  2. 2Escuchar el audio
  3. 3Apagar y volver a usar
1

Probar con una imagen

En la página que se abrió al iniciar VisionNav:

  1. Busque el recuadro verde POST /api/detect y haga clic sobre él.
  2. Haga clic en «Try it out» (probar).
  3. En file, elija una foto. Hay fotos de ejemplo en la carpeta test_images.
  4. Haga clic en el botón azul «Execute» (ejecutar).

En unos segundos aparece la respuesta. Busque narrativa_final: ahí está la descripción. Por ejemplo:

Parece que estás en una sala de estar. Sofá a tu derecha a aproximadamente
3 pasos. Mesa de comedor frente a ti a aproximadamente 4 pasos.
El paso al frente está bloqueado. Puedes avanzar hacia la izquierda.

Si cerró la página, ábrala de nuevo con esta dirección:

http://127.0.0.1:8000/docs
2

Escuchar el audio

Para recibir la descripción como audio, repita los pasos anteriores y, antes de hacer clic en «Execute», cambie audio a true.

La respuesta tendrá un enlace «Download file» para descargar el audio y escucharlo.

3

Apagar y volver a usar

  • Para apagar: cierre la ventana negra.
  • Para volver a usar: haga doble clic en iniciar.bat.

Si algo no funciona

Haga clic en el problema que tiene para ver la solución.

Dice «No se encontró Python»

Python no se instaló o se instaló sin marcar «Add python.exe to PATH».

  1. Abra de nuevo el instalador de Python.
  2. Elija «Modify» o vuelva a instalarlo marcando esa casilla.
  3. Haga doble clic otra vez en instalar.bat.
Aparece «Windows protegió su PC»

Haga clic en «Más información» y luego en «Ejecutar de todas formas». Windows muestra este aviso con los archivos descargados de internet.

La instalación se detuvo o se cortó el internet

Haga doble clic otra vez en instalar.bat. Lo que ya quedó listo no se vuelve a descargar.

La descripción sale muy simple o no hay audio

Lo más probable es que falte una clave o esté mal copiada.

  1. En la carpeta de VisionNav, abra el archivo .env con el Bloc de notas.
  2. Revise que después de GROQ_API_KEY= y de AZURE_SPEECH_KEY= esté su clave, sin espacios, y que AZURE_SPEECH_REGION= tenga la región de su recurso.
  3. Guarde el archivo, cierre la ventana negra y abra de nuevo iniciar.bat.
El navegador dice «No se puede acceder a este sitio»

VisionNav tarda unos segundos en arrancar. Espere y recargue la página. Si la ventana negra se cerró sola, ábrala otra vez con iniciar.bat y lea el mensaje que muestra.

No veo el archivo .env

Windows a veces oculta los archivos que empiezan con punto. En la carpeta, abra el menú «Ver» y active «Elementos ocultos».

Opciones avanzadas

Para personas que ya usan la terminal. Si siguió la pestaña «Instalar», no necesita nada de esto.

Instalación manual

git clone https://github.com/BrianGomezM/vision-api-object-detection.git
cd vision-api-object-detection
python -m venv .venv
.venv\Scripts\activate
pip install --index-url https://download.pytorch.org/whl/cpu torch==2.13.0 torchvision==0.28.0
pip install -r requirements.txt
copy .env.example .env
python run.py

Antes de ejecutar python run.py, escriba sus claves en .env y deje el archivo yolo26s.pt en la carpeta del proyecto.

Docker

La imagen incluye el modelo ya verificado.

docker build -t visionnav-api .
docker run -p 8000:8000 -e GROQ_API_KEY=su_clave -e AZURE_SPEECH_KEY=su_clave -e AZURE_SPEECH_REGION=su_region visionnav-api
