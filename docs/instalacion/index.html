Instalar VisionNav API

Siga estos pasos para tener el servicio funcionando en su computador con Windows. No necesita saber programar: la mayor parte se hace con doble clic.

  • Tiempo: unos 15 minutos
  • Espacio: unos 2 GB
  • Requiere internet

Pasos

  1. Instalar Python
  2. Descargar el proyecto
  3. Conseguir las claves
  4. Ejecutar el instalador
  5. Iniciar la API
  6. Probar con una imagen
1

Instalar Python

VisionNav funciona con Python, un programa gratuito. Si ya lo tiene en la versión 3.13 o 3.12, pase al paso 2.

  1. Descargue Python 3.13 desde la página oficial.
  2. Abra el instalador.
  3. Antes de continuar, marque la casilla «Add python.exe to PATH», en la parte inferior de la primera ventana.
  4. Haga clic en «Install Now» y espere a que termine.
Descargar Python
2

Descargar el proyecto

Descargue el proyecto en un archivo ZIP y descomprímalo en una carpeta fácil de encontrar, por ejemplo en Documentos.

Descargar el proyecto (ZIP)

Para descomprimir: clic derecho sobre el archivo, «Extraer todo…» y luego «Extraer».

3

Conseguir las claves

VisionNav usa dos servicios externos: uno redacta la descripción y otro la convierte en voz. Cada uno entrega una clave gratuita, que es como una contraseña para usar el servicio.

  • Groq (descripción): inicie sesión y cree una clave en «API Keys».
  • Google AI Studio (voz): inicie sesión y elija «Get API key».
Abrir Groq Abrir Google AI Studio

No comparta sus claves. Guárdelas solo en su computador; el instalador las escribe en el archivo .env de la carpeta del proyecto.

4

Ejecutar el instalador

En la carpeta del proyecto, haga doble clic en instalar.bat. Se abrirá una ventana negra que:

  1. comprueba que Python esté instalado;
  2. prepara un espacio de trabajo propio del proyecto;
  3. instala las librerías necesarias (es la parte más lenta);
  4. descarga el modelo de detección y verifica que sea el correcto;
  5. le pide las dos claves del paso 3. Pegue cada una con Clic derecho y presione Enter.

Cuando vea «Instalación terminada», cierre la ventana.

Si aparece «Windows protegió su PC», haga clic en «Más información» y luego en «Ejecutar de todas formas». Windows muestra este aviso con los archivos descargados de internet.

5

Iniciar la API

Haga doble clic en iniciar.bat. Después de unos segundos se abrirá en el navegador la página de prueba de la API.

Mientras la ventana negra esté abierta, la API funciona en esta dirección:

http://127.0.0.1:8000

Para detener la API, cierre la ventana negra. Para usarla otra vez, vuelva a abrir iniciar.bat; no hace falta instalar de nuevo.

6

Probar con una imagen

En la página que se abrió en el navegador:

  1. Abra la sección POST /api/detect.
  2. Haga clic en «Try it out».
  3. En file, elija una imagen. Hay ejemplos en la carpeta test_images del proyecto.
  4. Haga clic en «Execute».

En unos segundos verá la respuesta. El campo narrativa_final contiene la descripción de la escena, por ejemplo:

"Parece que estás en una sala de estar. Sofá a tu derecha a aproximadamente
3 pasos. Mesa de comedor frente a ti a aproximadamente 4 pasos.
El paso al frente está bloqueado. Puedes avanzar hacia la izquierda."

Para recibir solo el audio, cambie audio a true antes de hacer clic en «Execute».

Si algo no funciona

El instalador dice «No se encontró Python»

Python no se instaló o se instaló sin marcar «Add python.exe to PATH». Vuelva a abrir el instalador de Python, elija «Modify» o reinstálelo marcando esa casilla, y luego ejecute instalar.bat de nuevo.

La respuesta no trae descripción redactada o no trae audio

Revise las claves en el archivo .env de la carpeta del proyecto. Puede abrirlo con el Bloc de notas: las líneas GROQ_API_KEY= y GOOGLE_API_KEY= deben tener su clave después del signo igual. Guarde el archivo y vuelva a abrir iniciar.bat.

El navegador muestra «No se puede acceder a este sitio»

La API tarda unos segundos en cargar el modelo. Espere y recargue la página. Si la ventana negra se cerró, vuelva a abrir iniciar.bat y lea el mensaje que aparece.

Se cortó la descarga durante la instalación

Ejecute instalar.bat otra vez. Lo que ya quedó instalado no se descarga de nuevo, y si el modelo quedó incompleto, lo vuelve a descargar.

Opción para personas técnicas: Docker

Si tiene Docker instalado, puede construir y ejecutar la imagen del servicio, que incluye el modelo verificado:

docker build -t visionnav-api .
docker run -p 8000:8000 -e GROQ_API_KEY=su_clave -e GOOGLE_API_KEY=su_clave visionnav-api

La documentación técnica completa está en el archivo README.md del proyecto.
